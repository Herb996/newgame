## 五、挑素材时要记住的几件事

1. **RPG 那 252 张不是 252 个特效，是 252 个"形状族"**：每族约 8~10 种配色、每族约 8~12 帧。真按"形状×颜色"数，可用素材约 2500 个。
2. **格 32×32，本项目地图格 64×64** → 用之前要么 2 倍放大（保持像素整数倍），要么只在"角色身上/武器尖端"这类小尺度用。
3. **配色是"行"，不是"列"** —— 想按群系/阵营换色，直接换行，不用改素材。
4. **`shield` 一张都没有（词表里预留了，252 张里没有对应的）、`beam` 只有 1 张（1245）、`mark` 只有 5 张**：地面指示（撤离圈、巡逻点、选中环）这一类基本得自己画，现成的只有 `1733 / 1734 / 1628 / 1762 / 1234` 几个扁椭圆地面环勉强能用。
5. **`creature` 那 4 张（1405/1714/1771/1772）不是特效**，是扇翅膀的小生物，误分类风险高，用前自己看一眼。
6. 三个包风格不合（Demo 立绘、章鱼宝箱、黑龙），**只有黑龙图里那三条像素特效带值得抠**。
